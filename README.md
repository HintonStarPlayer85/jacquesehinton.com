# JacqueseHinton.com

Static prototype for Jacquese Hinton's networking-first digital business card.

## Prototype goals

- Mobile-first experience for QR and NFC traffic
- One-tap contact save via vCard
- Quick email, phone, LinkedIn, booking, and share actions
- Clear hierarchy across Jacquese's professional ecosystem
- Lightweight static architecture suitable for GitHub Pages
- No CMS dependency during concept validation

The production domain should remain on the existing Canva site until this prototype is approved.
